Información extra

Datos que el bot puede usar además de tu sitio web.

Además de leer tu sitio, el bot puede usar lo que le cargues en la pantalla Información: promociones, listas de precios, condiciones, reglamentos. Hay dos formas de cargarla.

Cargar un texto

En «Cargar un texto», escribí o pegá la información:

  • Título: una referencia corta para reconocerla en la lista.
  • Contenido: el texto que el bot va a usar.
  • Vence (opcional): una fecha. Pasado ese día, el bot deja de usar esa información.

Tocá Guardar información.

Subir un PDF

Sirve para catálogos, listas de precios y reglamentos. En «Subir un PDF» elegí el archivo, poné un título (opcional: si lo dejás vacío se usa el nombre del archivo) y, si corresponde, una fecha de vencimiento.

El PDF tiene que tener texto. Un PDF escaneado como imagen no se puede leer. Si no podés seleccionar el texto con el mouse al abrirlo, es una imagen.

Qué conviene poner fecha de vencimiento

Todo lo que cambia: una promoción, una lista de precios, un horario especial de feriados. Así el bot nunca ofrece algo vencido.

Sacar información

En «Información cargada» ves todo lo que subiste. Con el ícono de eliminar de cada fila, esa información deja de estar disponible para el bot.
